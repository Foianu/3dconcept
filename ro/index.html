# flux de lucru

de la idee la realitate

#1 brief

cerere de proiect & ofertă personalizată

cerere

tu:

+ specifică scopul proiectului (vizualizare produs, randare arhitecturală, altele)

+ livrabilele dorite (imagini, model 3D, etc.)

+ eventuale planuri, schițe, fișiere CAD sau referințe vizuale

+ preferințe de stil, rezoluție

+ termenul limită dorit

+ opțional: buget estimat

ofertă

noi:

+ trimitem o propunere care include:

+ etapele fluxului de lucru

+ timp estimat

+ cost și grafic de plată

+ numărul de revizuiri

+ contract

+ se efectuează o plată în avans (de obicei 30–50%) pentru a începe lucrul

# concept

analiza proiectului & creație

+ concept

noi:

+ analizăm materialele și cerințele tale

+ punem întrebări de clarificare, dacă este necesar

+ începem conceptul, discutăm ideile împreună

+ propunem un moodboard

+ feedback

tu:

+ trimiți feedback

#implementare 3D

flux de lucru & validare proiect

modelare și randare 3D

noi:

+ creăm sau optimizăm modelul 3D într-o imagine 2D realistă

+ configurarea scenei (materiale, iluminare, unghiuri de cameră)

+ trimitem randări preliminare (clay/draft) pentru feedback

+ feedback

tu:

+ trimiți feedback (materiale, iluminare, unghiuri de cameră)

noi:

+ implementăm revizuirile agreate

#4 livrare

produs virtual

+ randare finală

noi:

+ odată ce scena este aprobată, randăm imaginile finale de înaltă calitate

+ aplicăm post-producție (iluminare, culoare, efecte)

+ livrare & plată finală

noi:

+ livrăm fișierele finale în formatul dorit (JPG, PNG, TIFF etc.)

+ opțional: fișierele sursă pot fi livrate contra unei taxe suplimentare

tu:

+ finalizezi plata
